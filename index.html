Base de Datos Gratuita en la Nube (Firestore)

Por defecto, la app guarda todo gratis en tu navegador. Si quieres sincronizar en tiempo real entre PC y celular usando una base de datos gratuita:

  1. Crea un proyecto gratis en console.firebase.google.com.
  2. Crea una base de datos Firestore Database (en modo prueba para empezar).
  3. Ve a Configuración del proyecto > Tus apps > App web y pega aquí el objeto firebaseConfig.
